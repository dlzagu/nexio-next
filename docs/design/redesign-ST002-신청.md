## 0. 이 화면의 주된 결정 한 문장 (P1)

> **"내 문제를 담당자가 바로 이해할 수 있게 적었는가."**

신청 화면의 성공 기준은 "빨리 제출"이 아니라 **"되묻지 않아도 되는 요청"**이다.

> ✅ **가설 기각 (2026-07-30 DB 실측)** — "반려·취소가 많은 건 신청 내용이 불충분해서"라고
> 추정했으나 **틀렸다.** 실제 사유를 조회해보니:
> _"시스템 고도화 이관"_ · _"CMS 내용 확인하여 정상처리 확인함"_ · _"문의 내용 변경 후 재상신 예정"_ ·
> _"중복등록"_ · _"해결됨"_ — 전부 **정상적인 업무 종결 형태**다. 제목도 구체적이고 잘 쓰여 있다.
> → **신청 화면의 입력 품질은 문제가 아니다.** 이 화면 개선의 우선순위를 높일 근거가 없다.
> 구현 순서에서 마지막(3순위)에 두는 판단이 유지된다.

## 2. 검증 — 순차 alert 8단계를 버린다

### 현재 (L2098~2144)

저장을 누르면 alert 이 하나씩 튀어나온다. 8개 다 비어 있으면 **8번 눌러야 한다.**

```
고객사를 선택해 주세요 → [확인] → 신청자를 선택해 주세요 → [확인] → …
```

### 재설계

| 시점        | 동작                                                          |
| ----------- | ------------------------------------------------------------- |
| 입력 중     | 형식 오류만 즉시 (이메일 형식 등)                             |
| 포커스 이탈 | 해당 필드 필수 검증 → 필드 아래 인라인 메시지                 |
| 제출 시     | 미충족 필드 **전체를 한 번에** 표시 + 첫 필드로 스크롤·포커스 |

필수 8개: 고객사 · 신청자 · 신청자 이메일 · 분야 · 제목 · (첫 섹션) · 증상 · 요청내용

> **이메일 누락은 특수 케이스다.** 사용자가 이 화면에서 고칠 수 없다
> ("신청자 이메일을 먼저 등록해 주세요"). → 인라인 오류가 아니라
> **차단 배너 + 등록 화면 링크**로 처리한다.

## 3. 계약시간 3종 — 입력이 아니라 정보 (P8)

`monthTime` · `remainTime` · `inProgressTime` 은 `disabled` 인데 **입력칸 모양**이다.
사용자는 채워야 할 칸으로 오인한다.

→ 하단 정보 스트립으로 분리. `remainTimeShowYn`(=`AddInfoVO.showYn`)이 'N' 이면 **영역 자체를 렌더하지 않는다** (P2).
→ 잔여시간이 음수/임박이면 색 강조 (원본에 `text-danger` 로직 있음).

## 4. 참조자 UI 3중 → 단일 컴포넌트

현재 `refGroupSelect`(그룹 선택) + `ccInput`(직접 입력) + `refEmail`(결과)이 따로 논다.

## 5. 이미지 붙여넣기 가드 — 유지한다

외부(메일/웹)에서 복사한 이미지는 저장되지 않아 원본이 차단하고 있다 (L1411, L2409).
**실사용 제약이므로 반드시 유지.** 다만 메시지를 행동 지향으로 바꾼다.

| 현재                                                                                       | 재설계                                                               |
| ------------------------------------------------------------------------------------------ | -------------------------------------------------------------------- |
| "외부에서 복사한 이미지는 저장되지 않습니다. 캡처하거나 파일로 저장한 뒤 붙여넣어 주세요." | 붙여넣기 시점에 **즉시** 인라인 경고 + `[파일로 첨부하기]` 버튼 제공 |

> 지금은 **저장 버튼을 누른 뒤**에야 알려준다 (L2409). 작성이 다 끝난 뒤 되돌아가야 한다.
