## 1. 🔴 정렬 — 서버가 지원하지 않는다는 게 핵심 문제

`EcoLineSearchVO` 필드 13개에 **정렬 관련 항목이 하나도 없다.**
`POST /eco/request/list` 는 정렬을 받지 못한다. 그리고 우리는 **Spring 을 수정하지 않기로** 했다.

### 해법 — 뷰를 둘로 나눠 각각 다르게 처리한다

데이터 프로파일이 여기서 답을 준다 (`../inventory/data-profile.md`).

| 뷰                       |          건수 | 데이터 취득                            | 정렬                                        |
| ------------------------ | ------------: | -------------------------------------- | ------------------------------------------- |
| **진행 중** (기본 뷰)    |     **270건** | `size` 를 키워 **한 번에 전부** 가져옴 | ✅ **클라이언트 정렬** — 전 컬럼, 즉시 반응 |
| **내 요청**              | 사용자별 소량 | 동일                                   | ✅ 클라이언트 정렬                          |
| **전체 검색** (아카이브) |      23,694건 | 서버 페이징 (`page`/`size`)            | △ **페이지 내 정렬만** — 한계를 UI에 명시   |

> **이래서 기본 뷰를 "진행 중 270건"으로 잡은 판단이 두 배로 옳다.** 사용자가 매일 쓰는 화면에서는
> 정렬·필터가 서버 왕복 없이 즉시 동작하고, 서버 API 를 건드릴 필요도 없다.
>
> ⚠️ 아카이브 뷰의 정렬 한계는 **숨기지 않는다.** "현재 페이지 내 정렬" 이라고 표기하거나,
> 정렬 시 안내를 띄운다. 전체 정렬이 필요해지면 그때 서버 API 확장을 별건으로 논의한다.

## 2. 필수 (MVP 없으면 못 만듦)

### `@tanstack/react-table` v8 — 테이블

- **해결하는 문제**: 컬럼 정렬(신규 요구 #1) · 컬럼 표시/숨김 · 리사이즈 · 페이지네이션
- **선정 이유**: headless(스타일 없음)라 디자인 시스템을 100% 우리 토큰으로 입힌다.
  shadcn/ui 의 DataTable 이 이걸 기반으로 하므로 통합 비용 0
- 조회 목록 7컬럼 + 대시보드 목록 위젯에 공통 사용

### `@tiptap/react` — 리치 텍스트 에디터

- **해결하는 문제**: 신규 요구 #2. 요청 내용(`remarks`) · 처리결과(`cause`/`process`/`answer`/`result`) · 댓글
- **선정 이유 3가지**:
  1. **저장 포맷이 HTML** → 기존 2.3만 건 데이터와 그대로 호환 (`<p>...</p>` 실측 확인)
  2. **붙여넣기 핸들러 제어 가능** → 원본의 "외부 이미지 차단" 가드를 그대로 구현.
     게다가 **붙여넣기 시점에 즉시** 막을 수 있다 (원본은 저장 버튼 누른 뒤에야 알려줌)
  3. React 네이티브 — summernote 는 jQuery 의존이라 이식 대상이 아님

### `isomorphic-dompurify` — HTML 새니타이즈

- **해결하는 문제**: 기존 저장 HTML 을 렌더할 때의 XSS
- 🔴 **선택이 아니라 필수.** 2.3만 건이 HTML 로 저장돼 있고, 그중 78.6%가 비공개 문서다.
  새니타이즈 없이 `dangerouslySetInnerHTML` 로 그리면 즉시 취약점이 된다
- Tiptap 출력과 **기존 데이터 표시** 양쪽 모두에 적용

### `@tanstack/react-query` — 서버 상태

- **해결하는 문제**: 대시보드 API 중복 호출 (`recent-requests` 3회 등 → 1회)
- 캐싱·중복제거·리페치가 기본 제공. BFF 호출을 전부 이걸로 통일

### `react-hook-form` + `zod` — 폼과 검증

- **해결하는 문제**: 신청 화면의 순차 alert 8단계 → 인라인 검증
- `zod` 스키마는 `../inventory/schema.md` 의 VO 정의에서 그대로 도출.
  **동일 스키마를 BFF 응답 검증에도 재사용**한다

## 3. 권장

| 라이브러리     | 해결하는 문제                                                                                                                                        |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`nuqs`**     | 필터·선택 티켓을 **URL 쿼리로** 관리 → 공유·새로고침·뒤로가기 대응. `redesign-ST001-조회.md` §6 의 열린 질문("상세 열 때 URL 바꿀 것인가")에 대한 답 |
| **`recharts`** | 대시보드 차트 3종. shadcn/ui 의 chart 컴포넌트가 recharts 기반 → 팔레트를 디자인 시스템과 자동 공유. 원본 Chart.js 를 굳이 유지할 이유 없음          |
| **`date-fns`** | 날짜 포맷·비교. 이상치(`1900-01-01` 1,252건, `2105년` 3건) 처리 로직을 한 곳에                                                                       |
| **`sonner`**   | 토스트 알림 (shadcn 표준). 저장·상태변경 피드백                                                                                                      |
| **`cmdk`**     | 검색형 Combobox — **모듈 26개** 선택에 필요. shadcn Command 에 포함돼 별도 설치 불필요                                                               |

## 5. 채택하지 않는 것

| 후보                         | 왜 안 쓰나                                                                                                                       |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| jQuery / summernote / jqGrid | 원본 스택. React 로 가는 이상 이식 대상이 아님                                                                                   |
| Chart.js                     | recharts 가 shadcn 과 통합됨. 둘 다 쓸 이유 없음                                                                                 |
| Redux / Zustand 등 전역 상태 | 서버 상태는 react-query, URL 상태는 nuqs, 폼은 react-hook-form 이 가져간다. **남는 전역 상태가 거의 없다.** 필요해지면 그때 추가 |
| MUI / Ant Design             | 디자인 시스템을 직접 만들기로 했다. 완성형 UI 킷은 토큰을 덮어써서 오히려 방해                                                   |
| 무거운 날짜 피커 라이브러리  | shadcn Calendar + date-fns 로 충분                                                                                               |
