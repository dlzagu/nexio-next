# ADR-0002: MVP 구현 단계에서는 개발 스키마를 직접 조회한다 (Spring 릴레이는 보류)

- 날짜: 2026-07-30
- 상태: **대체됨 (ADR-0004)** — '운영 전환 시 ADR-0001 로 되돌린다'는 전제가 사라졌다.
  회사 DB 조회를 자체 SQLite + 가상 시드로 바꿨다. 역사 기록으로 남긴다.

## 맥락 (왜 이 결정이 필요했나)

ADR-0001 은 운영 아키텍처를 정했다 — BFF 가 사용자의 세션 쿠키를 Spring 에 릴레이한다.
그런데 그 경로는 **살아 있는 Spring 세션이 있어야** 동작한다. 화면을 만드는 단계에서는
매 요청마다 브라우저 로그인 상태가 필요하고, 아직 검증되지 않은 항목도 남아 있다
(P1.s7 — 세션 쿠키만 릴레이해도 200 이 오는지).

사용자가 개발 DB(원본 개발 스키마) 접속 정보를 제공하며 **"개발 스키마를 일단 사용"**
하라고 지시했다(2026-07-30). UI/UX 를 실데이터로 만드는 것이 이 단계의 목표다.

## 결정

`src/lib/data/*` 에 **개발 스키마를 직접 읽는 어댑터**를 두고 화면을 그 위에 올린다.

- **read-only 강제** — `src/lib/db.ts` 의 `select()` 가 `SELECT`/`WITH` 이외의 구문을
  기계적으로 거부한다. 주석으로 숨긴 구문도 제거 후 검사한다.
- **쓰기는 기본 차단** — `ALLOW_DEV_WRITES` 기본 `false`. 액션 라우트는 권한 판정까지만
  수행하고 `202 WRITE_DISABLED` 로 응답한다.
- **자격증명은 `.env.local` 에만** 두고 코드에 기본값을 넣지 않는다(누락 시 즉시 실패).
- **경계는 유지** — 화면은 `src/lib/data/*` 만 보고, 원본 테이블·컬럼명은 그 안에 갇힌다.
  Spring 릴레이로 바꿀 때 교체 대상은 이 디렉터리 하나다.

## 결과 (트레이드오프)

- **얻는 것**: 로그인 없이 실데이터(23,473건)로 화면을 만들 수 있다. 코드 매핑·이상치·
  빈 상태 같은 문제가 개발 중에 드러난다(실제로 4건 발견 — 아래).
- **포기하는 것**: Spring 이 하던 권한 판정을 **우리가 다시 구현**해야 한다. 이중화는
  `ux-principles.md` P6 이 경계한 바로 그 안티패턴이다 → **임시 조치임을 명시**하고
  `scopeClause()` 한 곳에 모아 fail-closed 로 짰다. 운영 전환 시 이 함수는 삭제된다.
- 쓰기 경로(신청 저장·액션·댓글)는 UI 까지만 완성돼 있고 실제 저장은 미구현이다.

## 이 결정 덕에 개발 중에 잡힌 것

| 발견 | 내용 |
|---|---|
| 코드 매핑 오류 | `B1GUBUN` 은 분야(B1GUBUN1)가 아니라 **운영시스템 ID**(`COMPANY_OPER_SYSTEM`)였다. 문서 추정이 틀렸다 |
| `REQTYPE` 정체 | `MIGRATION` 18,274건 = 구시스템 이관분. 1900-01-01 날짜 1,252건의 정체 |
| 이스케이프 HTML | `CAUSE`·`ANSWER`·`OKREMARKS`·`REMARKS`·`TITLE` 이 **이스케이프된 HTML**로 저장돼 있다. 그대로 렌더하면 태그가 글자로 보인다 |
| `OKREMARKS` 중복 | 분리 필드(원인·답변·결과)를 이어 붙인 레거시 요약이라 함께 렌더하면 내용이 두 번 나온다 |

## 검토한 대안

- **처음부터 Spring 릴레이** — 탈락: 사용자 지시와 어긋나고, 로그인 세션 없이는 화면 작업이
  진행되지 않는다. P1.s7 미검증 상태에서 막히면 UI 작업 전체가 멈춘다.
- **픽스처(가짜 데이터)로 UI 만들기** — 탈락: 실데이터가 드러낸 위 4건을 전부 놓친다.
  특히 비공개 78.7%·완료 99% 같은 분포는 화면 설계를 바꾸는 정보다.

## 운영 전환 체크리스트

- [ ] P1.s7 검증 — 세션 쿠키 릴레이로 `/eco/request/list` 200 확인
- [ ] `src/lib/data/*` 를 Spring 호출로 교체 (`redirect: "manual"` 필수 — ADR-0001)
- [ ] `scopeClause()` 삭제 — 테넌트 격리·비공개 제한은 서버가 판정한다
- [ ] `src/lib/session.ts` 의 페르소나 전환·`/api/session` 삭제
- [ ] `mssql` 의존성과 `DB_*` 환경변수 제거
