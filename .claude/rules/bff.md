# route handler 규칙 (`src/app/api/**`)

> 이 파일은 API 라우트를 만질 때 **자동으로 주입된다.** 틀리면 다음 작업이 통째로
> 틀린 전제 위에서 시작하므로, 코드가 바뀌면 여기부터 고친다.
>
> ⚠️ 예전 버전은 Spring 백엔드를 호출하는 BFF 규칙(세션 릴레이·302 처리·CSRF)이었다.
> **그 연동은 폐기됐다**(ADR-0004). 라우트는 이제 자체 SQLite/libSQL 을 직접 읽고 쓴다.
> 원본 시스템의 관찰 기록은 `docs/inventory/api-map.md` 에 역사로 남아 있다.

## 틀리면 조용히 망가지는 것들

### 1. 권한은 **여기서** 집행된다

화면의 `canDo()` 는 버튼을 그릴지 정할 뿐이다. 요청을 막는 것은 라우트다.

```ts
const ticket = await getTicket(echoNum, user); // ← 가시성 게이트를 지난 조회
if (!ticket) return 404; // 못 보는 건은 "없는" 건이다
if (!canDo(action, ticket, user, config)) return 403;
```

- 클라이언트가 보낸 티켓 상태를 믿지 않는다. **서버가 다시 읽어** 판정한다.
- 규칙에 없는 (액션, 상태, 역할) 조합은 전부 거부 — fail-closed.
- 🔒 **취소는 신청자 본인만.** 회사 정책이라 담당자에게 주지 않는다.
- 설정을 못 읽었을 때 건너뛰지 않는다 — `!config?.usesApproval` 처럼 **모르면 차단**.

### 2. 존재를 흘리지 않는 거부는 403 이 아니라 **404**

타사 티켓·첨부에 403 을 주면 "그 번호는 있다"는 사실이 새어 나간다. 가시성 밖이면
없는 것처럼 답한다 (`getTicket`·`getAttachment` 가 `scopeClause` 로 이미 그렇게 만든다).

### 3. 클라이언트가 보낸 **마스터 값**을 서버가 다시 조회한다

콤보박스 목록은 편의일 뿐 권한 경계가 아니다. 신청자·운영시스템·모듈이 그 고객사의
것인지 SQL 로 다시 확인하고, 어긋나면 거부한다. 고객사 사용자의 `custCode` 는 폼 값과
무관하게 **본인 회사로 고정**한다.

### 4. 성공은 `200`/`201` 뿐 — 쓰기가 잠기면 `202`

```ts
if (!devWritesAllowed()) return 202; // 권한 판정까지는 통과했다는 뜻
```

`res.ok` 는 202 를 포함한다. **저장 안 됐는데 성공으로 알면 사용자가 초안을 지운다.**
화면 쪽도 `res.status === 200` 으로 좁혀 받는다.

### 5. 쓰기는 한 트랜잭션으로 묶어 `write()` 에 넘긴다

상태 변경·이력 로그·첨부를 각각 커밋하면 중간 실패 때 **이력 없는 티켓**이 남는다.
`select()` 는 SELECT/WITH 만, `write()` 는 INSERT/UPDATE 만 통과시킨다 —
관문을 넓히지 않는다 (ADR-0006).

### 6. 입력 검증은 `src/lib/schemas.ts` 의 zod 를 **폼과 공유**한다

실패는 `400 { code: "BAD_REQUEST", detail: issues }`.
⚠️ 형식(정규식)만 보고 통과시키지 않는다 — `2026-13-40` 은 날짜 정규식을 통과하고,
뒤따르는 범위 비교는 `Invalid Date` 라 **거짓**이 되어 그대로 저장된다.

### 7. 첨부는 **디코드한 실제 바이트**로 다시 잰다

`size`·`mime` 은 요청 본문이라 얼마든지 바꿔 보낼 수 있다. 확장자와 MIME 이 함께
맞아야 하고, 다운로드는 언제나 `attachment` + `nosniff` 로 내려보낸다 (ADR-0008).

## 이름 변환은 데이터 계층 경계에서만

원본 컬럼명(`CONTENT`·`ECHONUM`·`PUBLICYN`)은 `src/lib/data/` 밖으로 나가지 않는다.
라우트와 화면은 정규화된 타입만 본다 (`docs/design/types-spec.md`).

## 새 라우트를 추가하면 테스트도 추가한다

`tests/routes.test.ts` — 쿠키를 갈아 끼워 페르소나를 바꾸고 핸들러를 직접 호출한다.
**"버튼이 없다"가 아니라 "직접 불러도 거부된다"** 를 고정한다.
